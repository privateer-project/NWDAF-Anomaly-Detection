⚙️ Settings

This page allows you to process instances and generate XAI (eXplainable AI) visualizations using SHAP and LIME algorithms.

🔄 Real-time Processing Status: The interface provides live feedback during processing, showing the progress of both SHAP and LIME calculations with timestamps and status indicators.

💾 Persistent State: Your processing status is automatically saved and restored when navigating between pages, so you won't lose progress if you switch to other sections.

You can load instance data in two ways:

1. 📁 Load dataset: Upload a JSON file containing dataset using the "Load dataset" button. This will send the file to the backend via /api/dataset.

2. 📝 Load Instance String JSON: Provide a valid JSON payload in the Instance Payload field and click "🚀 Explained Instance". This will process the instance using /api/shap/calculate/string_json and /api/lime/calculate/string_json endpoints.

📊 Processing Flow:
  • Instance validation and JSON parsing
  • SHAP calculation (⌛ → ✅)
  • LIME calculation (⌛ → ✅)
  • Data available for visualization in other components

The JSON payload must follow the required structure, including fields such as data, device, requires_grad, and shape. An example instance from startup_dataset.json is pre-loaded for demonstration.

🎯 Visual Feedback: The interface shows processing status with color-coded indicators, progress messages, and completion timestamps. The button becomes disabled during processing to prevent multiple simultaneous requests.

If you need to change the dataset or model, upload new files using the respective file inputs. This streamlined process ensures you can seamlessly switch datasets, models, and instance payloads while generating the necessary XAI visualizations.
