⚙️ Settings

This page allows you to generate graphics based on preloaded models, datasets, and instance payloads.

By default, the model and dataset are cached. To generate graphics, you need to provide a valid JSON payload in the Instance Payload field. This payload must follow the required structure, including fields such as data, device, requires_grad, and shape.

After entering the payload, click "Load Instance" to process the instance. The system will first calculate SHAP values and then LIME values. Once completed, a confirmation message will appear.

If you need to change the dataset or model, click "Fetch Datasets" to retrieve available datasets, select the desired one, and do the same for models by clicking "Fetch Models". After selecting both, click "Load Data" to load the new configuration and wait for confirmation that the data has been loaded. Then, you can provide a new JSON payload and generate the corresponding visualizations.

This streamlined process ensures you can seamlessly switch datasets, models, and instance payloads while generating the necessary visualizations.
